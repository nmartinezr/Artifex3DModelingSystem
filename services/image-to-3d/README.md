# Image to 3D Service

Provider-neutral Image → 3D orchestration boundary.

Candidate providers include TRELLIS, SPAR3D, TripoSR/Stable Fast 3D and Hunyuan3D. Provider-specific SDKs, options and result types must be isolated behind a common ARTIFEX contract.

Generated output is raw geometry and must enter the canonical Project Model and geometry-validation pipeline before being treated as manufacturing-ready.
